Política de Privacidade — Cclipsebot

Seus dados, tratados de forma simples e transparente.

Última atualização: 27 de setembro de 2026

1. Dados utilizados

Para oferecer seus recursos, o Cclipsebot pode armazenar informações como:

• ID de usuário do Discord
• XP e nível
• quantidade de Sonhos
• sequência e data do daily
• títulos e auras
• cosméticos e inventário
• informações necessárias para o funcionamento dos perfis
• contadores relacionados à atividade

2. Mensagens

O sistema de progressão pode detectar atividade para conceder XP. O conteúdo textual das mensagens não precisa ser armazenado no banco de perfis para esse funcionamento.

3. Finalidade dos dados

Os dados são utilizados para fornecer recursos como perfis, níveis, rankings, economia virtual, conquistas, títulos, cosméticos e demais funcionalidades do Cclipsebot.

4. Compartilhamento

Os dados dos perfis do Cclipsebot não são vendidos a anunciantes.

5. Armazenamento

Os dados necessários ao funcionamento do aplicativo são armazenados na infraestrutura utilizada pelo Cclipsebot.

6. Exclusão

Um usuário poderá solicitar a exclusão dos dados associados ao seu perfil entrando em contato com a administração responsável pelo Cclipsebot.

7. Segurança

São utilizadas medidas razoáveis para limitar o acesso aos dados necessários ao funcionamento do aplicativo.

8. Alterações

Esta política poderá ser atualizada conforme novos recursos sejam adicionados ao Cclipsebot.
